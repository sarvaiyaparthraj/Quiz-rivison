# 📝 JavaScript Quiz Application

A responsive and interactive **Quiz Application** developed using **HTML5, CSS3, Bootstrap, and JavaScript**. The application displays multiple-choice questions one by one, allows users to navigate through them using the **Next** button, and shows a completion message after the final question.

## 🚀 How to Run

1. Clone this repository.

```bash
git clone https://github.com/your-username/quiz-application.git
```

2. Open the project folder.

3. Open **index.html** in your browser.

4. Read each question carefully.

5. Click **Next** to move to the next question.

6. After the last question, the application displays **Quiz Completed!**
